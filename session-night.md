   - **RAG/Retrieval**: Answers *What educational information should be taught?* based on source documents.

5. **Fallback Strategy**: If local Text-to-Video is unavailable or slow, falls back to Image/Comic-style scenes + audio narration to keep the learning loop functional.
6. **MVP Focus**: Complete end-to-end loop covering profile selection, topic/material input, RAG, story synthesis, scene narration + visual generation, and final video assembly.

# BAD: query inside loop

# Code Review Report — EduTale Platform (Frontend & Backend)

**Intent Summary:** EduTale transforms academic materials (Text, PDF, Images) into age/grade/interest-personalized visual stories using EasyOCR, a sentence-chunked RAG vector pipeline, structured LLM story generation, scene decomposition, and TTS audio narration synthesis, rendered through a React + Tailwind CSS web application and served via FastAPI.

### 1. Critical Issues 🔴 (Must Fix Before Production)

1. **Unbounded In-Memory Storage (`backend/app/core/database.py` & `rag/vector_store.py`)**
   - **Risk:** High VRAM/RAM OOM risk in production (Render / Cloud deployment).
   - **Details:** `Database._lessons`, `Database._students`, and `VectorStore._chunks`/`_vectors` store all data in Python global dictionary variables without eviction limits or persistence to disk/DB.
   - **Impact:** Server restart wipes all user stories; heavy usage will cause memory leak crashes.
   - **Recommendation:** Integrate SQLite / PostgreSQL with SQLAlchemy and persistence for vector stores (e.g., ChromaDB, FAISS, or PGVector).

2. **Blocking Operations in Async Route Handlers (`backend/app/api/routes/lessons.py`)**
   - **Risk:** Server thread blocking under concurrent requests.
   - **Details:** The endpoint `upload_and_create_lesson` in `lessons.py` is defined as `async def`, but executes heavy CPU/GPU bound tasks (`content_pipeline.process_content_input`, EasyOCR model execution, and PyTorch embeddings) directly in the main event loop thread.
   - **Impact:** Freezes the entire FastAPI event loop for other incoming HTTP requests during OCR or embedding processing.
   - **Recommendation:** Use `fastapi.BackgroundTasks` or offload processing to an async task worker (Celery, Arq, or `fastapi.concurrency.run_in_threadpool`).

3. **Loose CORS Middleware Configuration (`backend/app/main.py:27`)**
   - **Risk:** Cross-Origin Security Vulnerability (OWASP).
   - **Details:** `allow_origins=["*"]` and `allow_credentials=True` are used together in CORS middleware.
   - **Impact:** Browsers and security scanners flag wildcard origins with credential sharing as unsafe.
   - **Recommendation:** Restrict `allow_origins` in `Settings` to explicit frontend domain origins (e.g. `http://localhost:3000`).

1. **Hardcoded Fallbacks in Models & Services (`models/llm/story_model.py` & `models/ocr_model.py`)**

2. **Mock Audio Synthesis in TTS Adapter (`models/tts/tts_model.py:43`)**
   - **Details:** `_generate_synthetic_pcm_wav` generates a raw 440Hz sine wave tone for scene narration instead of spoken voice speech.
